# 🚀 SynCube

A modern, real-time chat application frontend inspired by Slack. Built with React and modern UI/UX practices, supporting channels, direct messages, notifications, and real-time updates.

---

## 🚀Live 
[Hosted Link](https://slack-clone-frontend-psi.vercel.app/)

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Zustand (State Management)
- Socket.io Client
- Axios
- React Router

---

## ✨ Features

- 🔐 Authentication (Login / Signup)
- 💬 Real-time messaging (Channels & DMs)
- 🟢 Online/Offline user status
- 🔔 Notifications system
- 📁 File & media sharing
- 👍Message reactions
- 🧵Threaded replies 
- ⚡ Fast and responsive UI
- 🧠 State management with Zustand
- 🌐 API integration with backend

---

``` cs
src/
│── components/

│── store/

│── App.jsx
│── main.jsx

```

## ⚙️ Environment Variables

Create a `.env` file:
```js
VITE_API_URL=https://syncube-backend.onrender.com
```

---

## 🚀 Getting Started

### 1. Clone the repo
``` bash
git clone https://github.com/abhikainthla/slack-clone-frontend.git

```

### 2. Install dependencies
``` bash
npm install
```


### 3. Run development server
```bash
npm run dev
```


---

## 🔗 API Integration

All API calls are handled via Axios instance:

```js
baseURL = import.meta.env.VITE_API_URL
```


---

## 📦 Build

```bash
npm run build
```
